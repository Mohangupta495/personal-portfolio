## ✨ Features

### 🎨 Visual & Interactive Design
* **Dual Core Themes**: Instant switching between Obsidian Dark (obsidian black background with deep slate gradients) and Slate Light (crisp off-white background with soft grid lines).
* **Dynamic Accent Color Picker**: Toggle between four interactive theme colors on-the-fly (**React Blue**, **Cyber Purple**, **Emerald Mint**, and **Neon Amber**) to customize glows, borders, highlight badges, and button highlights.
* **Scroll-Reveal Animations**: Lightweight scroll monitoring utilizing the native `IntersectionObserver` API for smooth slide-in page elements.
* **Zero Emojis System**: 100% vector-based, using custom vector SVGs and Lucide icons for brand representation and metadata.

### 📱 Product Showcase & Simulations
* **High-Fidelity CSS Device Frames**: iPhone and Android phone mockups housing real Google Play and Apple App Store screenshots.
* **Floating Interactive Overlays**: Tap components on the simulated phone screens to trigger WebRTC voice/video dial screens, SQLite offline database sync toggles, access logging, and coordinate tracking telemetry.
* **Live Website Previews**: A custom built-in desktop browser frame iframe modal that lets users browse the live deployed sites (like [agrim.app](https://agrim.app/) and [doorvi.co](https://www.doorvi.co/)) directly inside the portfolio modal.

## 📦 Getting Started

### Prerequisites
* **Node.js**: `v20.9.0` or higher (required by Next.js 16)
* **Package Manager**: `Yarn` (recommended) or `npm`

### Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:Mohangupta495/personal-portfolio.git
   cd personal-portfolio
   ```

2. Install dependencies:
   ```bash
   yarn install
   ```

### Development
Start the local development server:
```bash
yarn dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to preview the site.

### Build
Compile a production build:
```bash
yarn build
```
The optimized build files will be compiled under `.next/` and ready for server or static file generation exports.
